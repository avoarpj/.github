👋 **Seja bem-vindo a organização do projeto Avoar.**

Acreditamos que dados abertos **de verdade** precisam passar por __**tratamento, padronização e relacionamentos diretos**__ antes de serem disponibilizados para uso. <br>
> Nossos dados são gerados a partir de novas interpretações, a maioria dos datasets aqui são derivados: mandatos, filiações partidárias, pessoas públicas, ...

O projeto possui um nível **altíssimo** de eficiência volumétrica no armazenamento.<br>
Precisamos de menos espaço para armazenar mais.<br>
Nossa base de dados de empresas, depois de gerada, possui ~15GB. Um computador mediano lida tranquilamente.

Se você quiser explorar os dados, comece fazendo setup do [Turi](https://github.com/avoarpj/turi) na sua máquina.

**REQUISITOS MÍNIMOS PARA RODAR O TURI** <br>
CPU: Ryzen 5 5500U <br>
RAM: 16GB DDR4 <br>
DISCO: ~512GB SSD NVME <br>

**REQUISITOS RECOMENDADOS** <br>
CPU: Ryzen 5 9600x <br>
RAM: 64GB DDR4/DDR5 <br>
DISCO: ~512GB SSD NVME <br>

Para aqueles que não têm memória ram suficiente, considere usar swapfile de pelo menos 60GB (Para 16gb de ram físicos). <br>
A geração será mais lenta, mas suficientemente rápida (~1 hora).
